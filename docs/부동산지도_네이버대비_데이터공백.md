켜지는 것들이므로, 승인/한도가 풀리는 순서대로 바로 살아난다.

## 3. 아직 막힌 것 — 호출한도

| 데이터 | 서비스 | 증상 |
|---|---|---|
| 아파트 **전월세** | `1613000/RTMSDataSvcAptRent` | 승인은 돼 있는데 429 |

트래픽 증가를 신청해도 **그날 이미 소진한 카운트는 리셋되지 않는다.** 자정 지나고
`scripts.check_realestate_apis` 를 다시 돌려 확인할 것.

아파트 전월세는 전세/월세 탭뿐 아니라 **매매 카드의 전세가율·갭 계산**에도 쓰인다.
이게 막혀 있으면 매매 화면의 전세가율 배지도 함께 빈다.

**한도 산정 참고** — 전국 250개 시군구 × 1개월 = 서비스당 약 250콜/회.
유형 7종을 다 켜면 1회 최대 약 1,700콜. 서비스별 일 10,000콜이면 여러 번 갱신해도 남는다.

## 4. 엔드포인트를 못 찾은 것 — 확인 필요

네이버의 **단지정보 패널**(세대수·준공일·용적률·건폐율·주차·난방·시공사)에 해당한다.
우리 단지 상세에 슬롯(`static`)은 이미 있고 값만 비어 있다.

시도한 경로 11가지가 전부 `NO_OPENAPI_SERVICE_ERROR (코드 12) — 해당 오픈API 서비스가
없거나 폐기됨`:

```
1611000/AptListService3/getLegaldongAptList3     1611000/AptListService3/getSidoAptList3
1611000/AptListService2/getTotalAptList          1611000/AptListService2/getLegaldongAptList
1611000/AptListService/getTotalAptList           1613000/AptListService2/getTotalAptList
1611000/AptBasisInfoServiceV3/getAphusBassInfoV3 1611000/AptBasisInfoServiceV3/getAphusDtlInfoV3
1611000/AptBasisInfoServiceV2/getAphusBassInfoV2 1613000/AptBasisInfoServiceV2/getAphusBassInfoV2
1611000/AptBasisInfoService1/getAphusBassInfo    1611000/AptBasisInfoService/getAphusBassInfo
```

코드 12는 "경로가 틀림"과 "이 키로 활용신청한 적 없음"을 구분해 주지 않는다.
data.go.kr 검색어 — **한국부동산원**_공동주택 단지 목록제공 서비스 / **한국부동산원**_공동주택
기본 정보제공 서비스(K-apt). 활용신청 후 화면에 적힌 **정확한 요청 URL**을 확인해야 한다.

## 5. 공공데이터에 아예 없는 것 — 영구 공백

| 네이버 기능 | 왜 못 하나 | 대체 |
|---|---|---|
| **매물(호가) 목록** | 중개사 등록 호가는 민간 데이터. 정부 API는 계약 완료된 실거래만 제공 | 실거래로 대체 (실제 체결가라 오히려 정확) |
| **KB시세 / 호가 시세표** | KB국민은행 민간 데이터, 공개 API 없음 | 실거래 월별 평균/최저/최고 |
| **단지 사진·평면도** | 중개사·건설사 제공 자산 | 없음 |
| **단지 정확 좌표** | 실거래 API는 법정동까지만 준다 | 동 중심 + 단지명 해시 분산으로 근사 배치 (가격·면적·거래일은 실제값) |
| **재건축·개발호재 레이어** | 정비사업 정보가 지자체별로 흩어져 있고 전국 통합 API 없음 | 없음 |
| **동일매물 묶기 / 중개사 정보** | 매물 데이터가 있어야 성립 | 해당 없음 |
| **상업·업무용 / 토지 전월세** | 정부가 매매만 공개 | 매매만 표시(전세·월세 탭 자동 잠금) |

## 화면이 상태를 어떻게 알리나

- 403 → "이 서비스에 활용신청이 승인됐는지 확인하세요"
- 429 → "일일 호출한도를 넘겼습니다 — 자정 이후 다시 채워집니다"
- 전월세 없는 유형(상업·업무/토지/분양권) → 전세·월세 탭이 **비활성**, 이유는 툴팁
- POI 미적재 → "`python -m scripts.ingest_poi` 로 적재하세요"

빈 목록과 장애를 구분해서 보여주므로, 화면만 봐도 어느 쪽인지 안다.
